# ФизКат - консольная программа для учета прокатной техники и инвентаря

Программу можно использовать для добавления и удаления прокатной техники, шлемов, док-станции и, конечно, колы (мне было скучно добавлять что-то нормальное типа машины).

## Установка и использование

Требуется установленный компилятор C++, а также скачанные файлы ```main.cpp``` и ```main.exe```

Запускать программу нужно через файл ```main.exe```.

Для пользования нужно вводить команды в командной строке, которая открывается после запуска файла ```main.exe```. 

#### Список команд

| Команда | Для чего команда нужна |
|---|---|
| `add scooter id name energy score` | Добавить электросамокат |
| `add bike id name score` | Добавить велосипед |
| `add ebike id name energy score` | Добавить электровелосипед |
| `add helmet id name` | Добавить шлем |
| `add dock id name energy` | Добавить док-станцию |
| `add cola id name` | Добавить колу. Ну как же жить без любимого Добрый Кола? *(креативная часть)* |
| `list` | Вывести все позиции, отсортированные по ID |
| `energy` | Вывести суммарное суточное энергопотребление |
| `novice` | Вывести транспорт с рейтингом простоты не менее 6 |
| `count_novice` | Посчитать количество транспорта для новичков *(креативная часть)* |
| `size` | Вывести количество позиций |
| `focus id` | Выбрать позицию для фокуса |
| `show_focus` | Показать выбранную позицию или сообщение об удалении |
| `remove id` | Удалить позицию |
| `quit` | Завершить программу |

Имена и инвентарные номера в командах вводятся без пробелов.

## Ошибки

В коде были реализованы скрипты, реагирующие на ряд ошибок, чтобы программа не сломалась при неаккуратном использовании. Вот, какие ошибки могут возникнуть:

- `error: inspection rejected` — отказ после техосмотра, т.к. транспорт содержит в названии слово `broken`;
- `error: negative energy` — отрицательное или некорректное энергопотребление;
- `error: empty ID` — пустой инвентарный номер;
- `error: invalid score` — рейтинг простоты вне диапазона 1–10.

Также программа проверяет повторяющиеся ID, несуществующие команды и прочие ошибки, возникающие при некорректном вводе.

Техосмотр транспорта отклоняет названия, содержащие `broken` без учёта регистра.

Проверки выполняются до добавления объекта в парк, так что студенты могут не переживать о том, что оплатят пользование за поломанный скутер :)

## Креативная часть

Добавлен класс `Cola` — дополнительный вид инвентаря, который можно добавить командой `add cola`.

Также реализованы дополнительные команды `count_novice` для подсчёта транспорта, подходящего новичкам, и `size` для отображения количества позиций.

## Пример использования

Ввод:

```text
add scooter S-1 Model67 2.5 8
add bike B-1 Wroom 4
add scooter S-2 broken67 1.0 9
add helmet H-1 Cola
add dock D-1 Dock1 10.0
list
novice
energy
quit
```

Вывод:

```text
error: inspection rejected
B-1 Wroom
D-1 Dock1
H-1 Cola
S-1 Model67
S-1 Model67
12.5
```
